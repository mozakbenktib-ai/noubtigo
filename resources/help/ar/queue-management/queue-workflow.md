# إدارة الطابور وسير عمل التذاكر

يوفر نوبتيجو نظام إدارة طوابير ذكي يدعم وضعين تشغيليين: **الطابور البسيط** و **الطابور المتقدم**.

---

## مقارنة بين الوضعين

| الميزة | الوضع البسيط | الوضع المتقدم |
| :--- | :--- | :--- |
| **مناسب لـ** | شباك واحد، خدمة سريعة | عيادات متعددة، مكاتب مؤسسية |
| **الإجراءات** | التالي، تمرير، إكمال | التالي، تعليق، استئناف، تمرير، تحويل، أولوية |
| **الأولوية / VIP** | أساسي | تقييم أولوية متقدم مع دمج المواعيد |

---

## دورة حياة التذكرة

```
وصول العميل -> إصدار تذكرة (انتظار) -> استدعاء -> بدء الخدمة -> مكتمل
                                            |               |
                                       العميل غائب      تعليق مؤقت
                                            |               |
                                       (تمرير/إلغاء)     (استئناف)
```

### أزرار التحكم الرئيسية

1. **إصدار تذكرة**: يُنشئ رقم تذكرة تسلسلي فريد (مثل `A-014`) بناءً على بادئة الخدمة.
2. **استدعاء التالي**: يُطلق تنبيهاً بصرياً وصوتياً على شاشات العرض العامة ويرسل إشعار واتساب.
3. **تمرير**: يُستخدم عندما لا يكون العميل حاضراً عند استدعائه.
4. **تعليق مؤقت (Hold)**: يوقف الخدمة مؤقتاً (مثلاً أثناء جمع مستندات ناقصة) بدون إلغاء التذكرة.
5. **استئناف (Resume)**: يُعيد العميل المعلّق إلى حالة الانتظار ذات الأولوية.
6. **إلغاء / إعادة فتح**: يُلغي التذاكر غير الصالحة أو يُعيد التذاكر الملغاة عن طريق الخطأ.
