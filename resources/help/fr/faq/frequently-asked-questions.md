# Foire Aux Questions

### 1. Comment émettre un ticket pour un client sans rendez-vous ?
Cliquez sur **File d'Attente** dans le menu, puis sur **+ Émettre un Ticket**. Sélectionnez le service et entrez le numéro de téléphone du client.

### 2. Quelle est la différence entre File d'Attente et Rendez-vous ?
- **File d'Attente** : Pour les clients présents sans rendez-vous. Les tickets sont servis dans l'ordre séquentiel.
- **Rendez-vous** : Pour les réservations planifiées à une date et un créneau horaire précis.

### 3. Quand utiliser le Mode Simple ?
Utilisez le **Mode Simple** si vous gérez un seul guichet avec les boutons **Appeler Suivant** et **Terminer**.

### 4. Que se passe-t-il si un client ne se présente pas ?
Cliquez sur **Passer** ou **Mettre en Attente**. Si le client revient, cliquez sur **Reprendre**.

### 5. Puis-je rouvrir un ticket annulé ?
Oui ! Dans le **Mode Avancé** ou l'**Historique des Tickets**, localisez le ticket et cliquez sur **Rouvrir**.

### 6. Comment les clients suivent-ils leur position ?
Les clients peuvent scanner le **code QR** imprimé sur le ticket, ouvrir le lien envoyé par **WhatsApp**, ou consulter l'**écran d'affichage public**.

### 7. Comment changer la langue ou activer le Mode Sombre ?
Cliquez sur l'**icône de globe** pour choisir la langue. Cliquez sur l'**icône lune/soleil** pour basculer le Mode Sombre.
